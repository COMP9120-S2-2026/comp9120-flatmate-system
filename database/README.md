# HouseMatch PostgreSQL Database

## Setup

Create a PostgreSQL database named `housematch`.

Execute the SQL files in this order:

1. 01_schema.sql
2. 02_triggers.sql
3. 03_sample_data.sql

## Additional files

- 04_queries.sql: Database queries
- 05_transactions.sql: Multi-step transactions
- 06_tests.sql: Automated integrity tests
- 07_concurrency_manual.sql: Manual concurrency tests

The database contains 10 tables and 10 triggers.
